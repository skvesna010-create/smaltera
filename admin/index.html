Вход в админку

Админка сохраняет изменения прямо в ваш репозиторий GitHub, и сайт обновляется сам через 1–2 минуты. Для входа нужен ключ доступа GitHub — он хранится только в этом браузере.

Как получить ключ (2 минуты)
  1. Откройте github.com → Settings → Fine-grained tokens → Generate new token.
  2. Token name: smaltera-admin. Expiration: 1 год (или No expiration).
  3. Repository access: Only select repositories → выберите smaltera.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Нажмите Generate token, скопируйте ключ и вставьте сюда.

Никому не передавайте ключ. Если потеряете телефон или ноутбук — удалите ключ на GitHub и создайте новый.
